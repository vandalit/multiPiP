# Multi PiP — documentación del producto

Esta carpeta conserva la definición acordada del producto, el alcance del POC y
la hoja de ruta. La arquitectura de captura todavía no está validada: las
decisiones de producto no deben confundirse con una solución técnica ya probada.

## Documentos

- [PRD](./PRD.md): concepto, usuarios, comportamiento esperado, requisitos y
  decisiones de producto.
- [Alcance del POC](./POC.md): hipótesis técnicas, escenarios y criterios de
  aceptación para decidir si se continúa.
- [Hoja de ruta](./ROADMAP.md): fases y puertas de decisión, sujetas al resultado
  del spike.

## Estado

**Definición de producto inicial consolidada; spike de dos canales validado
manualmente.** Faltan pruebas de retirada independiente, geometría y
rendimiento antes de ampliar a tres slots. No comprometer aún arquitectura de
producto ni estimación de implementación.

## Registro de contexto

La definición se consolidó a partir del documento de viabilidad compartido y de
la conversación del 12 de octubre de 2026. Las selecciones expresas del usuario
se registran como decisiones; las preguntas que siguen abiertas se marcan como
pendientes y no se dan por resueltas por omisión.
